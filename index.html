Largura da via — Rotatória / Rua curva:
—
Selecione uma rotatória ou Rua curva e use − Via / + Via. Na Rua curva, somente a largura da pista é alterada, sem modificar o trajeto.

Objeto selecionado

Esta versão usa Fabric.js. As ruas são elementos independentes, criados ponto a ponto e entram sem faixas pintadas; as marcas viárias são ferramentas separadas. Selecione um objeto para usar as alças de largura, altura, tamanho geral e rotação. Use Delete para excluir.
